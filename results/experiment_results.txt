7. OBSERVATIONS

- All cache coherence simulator configurations completed.
- Padding reduced simulated bus transactions significantly.
- MOESI avoided forced writebacks by using cache-to-cache transfers.
- All counter configurations in the combined program produced correct final counts.
- Padded counters performed better than adjacent counters in the 2-thread and 4-thread combined tests.
- Two threads improved memory sweep execution time compared with one thread.
- Remote memory was slightly slower in the combined NUMA measurements.
- The VM uses virtual NUMA nodes, so these measurements should not be treated as physical multi-socket hardware results.

8. CONCLUSION

The experiment demonstrated the differences between MSI, MESI and MOESI cache coherence protocols, the effect of false sharing, and the influence of NUMA memory placement on execution time. Padding reduced cache-line sharing, while MOESI reduced memory writebacks through cache-to-cache transfers. Local memory placement showed a small performance advantage in the combined NUMA tests.
